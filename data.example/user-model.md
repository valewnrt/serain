# Alex, user model

Example. Copy `data.example/` to `data/` (gitignored), write about yourself
there and push it into the database with `pnpm memory:push --apply`.
Everything here is invented. Write it in whatever language you like; Serain
reads it in any language. The headings below are only a suggestion: they
structure the text, no code reads them.

## How to read this

This is the base knowledge about Alex. What Alex says in the chat is newer and
beats this text. Headings only structure; every line below them is a statement.
